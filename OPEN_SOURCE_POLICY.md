# Open-source policy

Pretty Busy Solutions uses licenses by artifact type rather than by accident.

## License selection

- **Apache-2.0** is used for protocol and standards-oriented work where an
  explicit patent grant is important. ProofRail is the current example.
- **MIT** is used for applications, libraries, utilities, and site code when a
  short permissive license is sufficient.
- Imported or forked work retains its original copyright and license notices.
  Repository ownership does not erase upstream authorship.

The license file in each repository is authoritative. This policy is not legal
advice and does not replace repository-specific notices.

## Minimum public-repository surface

Public software repositories should include:

1. a detected `LICENSE` file;
2. a `SECURITY.md` reporting path;
3. a direct quickstart or reproduction path;
4. automated integrity checks;
5. an explicit maturity and claim boundary; and
6. versioned release notes when a releasable artifact exists.
