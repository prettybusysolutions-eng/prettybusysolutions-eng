and revenue-critical operations.

outcomes remain inspectable. The fastest way to evaluate the work is to run a
public artifact—not to trust a claim.

## Operating standard

- Evidence before claims.
- Exact authority before consequential action.
- Provider observation before declared success.
- Reproducible failure tests, not demonstration-only happy paths.
- Explicit boundaries for experimental, pilot, and production-ready work.
- Versioned releases only after repository checks pass.

## Public-estate policy

- [Open-source policy](OPEN_SOURCE_POLICY.md)
- [Release policy](RELEASE_POLICY.md)
- Every public software repository must expose a license, a security policy, a
  testable entry point, and a release or an explicit pre-release status.
- Profile and website repositories are presentation surfaces, not installable
  products; they are not versioned like software packages.
